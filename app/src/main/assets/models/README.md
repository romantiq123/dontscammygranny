# Эта папка больше НЕ используется для самой модели

(2026-07-21, пересмотрено в тот же день) Модель GGUF (сотни МБ) раздувала APK
почти на порядок, поэтому её больше не кладут сюда и не бандлят в APK. Вместо
этого `LlamaCppExecutor` качает её напрямую с HuggingFace в `filesDir/models/` —
см. `app/src/main/kotlin/kz/invisibleshield/app/llm/LlamaCppExecutor.kt`
(`MODEL_URL`/`MODEL_FILENAME`).

Смена кандидата модели (ADR-003, финальный выбор — после бенча) — правка
`MODEL_URL`/`MODEL_FILENAME` там же, никаких файлов сюда класть не нужно:
целостность докачки проверяется по `Content-Length` сервера, а старый `.gguf`
удаляется автоматически (`cleanupStaleModels`).

Папка оставлена пустой намеренно — на случай, если в будущем снова понадобится
бандлить что-то как asset рядом с grammar-файлом.

**UX скачивания (сделано):** закачка больше не безусловная — она начинается только
после явного согласия пользователя (кнопка «Скачать»), по умолчанию в режиме
«только по Wi-Fi» (`llm/ModelPrefs.kt`, ADR-006). Без согласия модель не качается
ни на старте, ни из пайплайна; детект в это время работает на regex-слое.
